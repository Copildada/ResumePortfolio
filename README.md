## 🆘 Troubleshooting

### "Can't deploy"
- Check build logs in your platform dashboard
- Ensure all files are in the GitHub repo
- Try a fresh clone and push

### "Styles/scripts broken"
- Hard refresh (Cmd+Shift+R or Ctrl+Shift+R)
- Check DevTools console (F12) for errors
- Verify `index.html` is in the root folder

### "Resume download doesn't work"
- It's embedded in the HTML — should work automatically
- Try different browser if it doesn't

### "Want to update projects later?"
- Edit `PROJECTS` array in `index.html` (search for `const PROJECTS`)
- `git push`
- Done! Redeploys in 1–2 min
